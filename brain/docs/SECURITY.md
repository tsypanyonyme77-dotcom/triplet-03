# Security: threats, defences and the test that proves each

Written 5 Nov 2026 from the code. `uv run brain redteam` runs the attacks marked **A**; `uv run brain security-check` runs the invariants; the others are named tests. An **open** mark means it is not built or not proven; nothing here is claimed that a test does not show.

| # | Threat | Defence | Proof |
| --- | --- | --- | --- |
| 1 | A forged or unsigned reading | HMAC-SHA256 (or Ed25519) over canonical JSON; a missing or wrong signature is refused with a stated code | A1, A2 |
| 2 | A replayed reading or call | A reading's `sequence_no` must rise per sensor (and survives a restart); with `twin.max_age_s` set, a timestamp far from the clock is refused as `reading_stale` (off by default: scenarios replay old times); a call carries `issued_at` and a one-time `nonce` | A3, A24; `tests/test_signing_keys.py`, `tests/test_perception.py` (a call outside the skew and a repeated nonce are refused) |
| 3 | A stolen or old key | Key ids, validity dates, rotation with an overlap, `alg: none` refused ([KEYS.md](KEYS.md)) | A20, A21, A22; `tests/test_signing_keys.py` |
| 4 | A partner speaking as the Brain on the screen | Pushed events are limited to the partner's own namespace and take their source from the token; the screen ignores a `brain.*` event that was pushed; only the Guardian's push token may retract a verdict | A13, A14, A23; `tests/test_security.py` |
| 5 | Unauthorised use of the API | Scoped bearer tokens (read, analyse, push, approve, admin) off loopback; every route is classified (a test fails on one that is not) | A8 to A12 |
| 5b | A stolen long-lived token | Short-lived signed tokens (`brain token --sub ana --scope read,analyse --ttl 8h`), bound to an audience, expiring, revocable by id (`--revoke`); the static tokens still work for machines | `tests/test_tokens.py` |
| 6 | Flooding, oversize bodies | Per-caller rate limit (429 with `Retry-After`), body size limit (413) | A15, A16 |
| 7 | Prompt injection through an id or a value | Ids and every free-looking value field (`activity`, `anomaly_type`, `citizen_id`, `flags`...) are limited to `[A-Za-z0-9._:#-]{1,64}`; unknown value fields are dropped before any prompt | A5, A6, A7; `tests/test_llm_security.py` (30 hostile strings from `tests/data/injection_corpus.yaml`, each mapped to an OWASP LLM category, through ids, free-looking fields and unknown fields) |
| 8 | An agent that actuates | Agents get read-only tools; the tool registry refuses an actuator's name; only the gate calls the Twin (AST tests) | A19; `brain security-check`; `tests/test_llm_security.py` (a Twin that adds an actuator tool mid-run is reported as `brain.twin.capabilities.changed` and never used) |
| 9 | A high-impact action without a person | Valve and grid calls wait for a signed approval bound to the action, parameters and incident, single use, with an expiry | A17, A18; `tests/test_approval.py` |
| 10 | A tampered log | Hash-chained events, plus a signed head (`<log>.head`) so a log rewritten end to end fails `brain audit verify` | `tests/test_chain_anchor.py` |
| 11 | The MCP server used to act | Read-only tools, scope checks, DNS-rebinding protection, every call a `brain.mcp.called` event | `tests/test_mcpserver.py` |
| 12 | Personal data entering the Brain | Perception drops demographic fields; suspect scoring uses behaviour only | `tests/test_perception.py` |
| 13 | A secret in the repository | `.env` is git-ignored. **An incident:** a real Groq key was committed once (history of `d8a838b`) and removed from the file on 5 Nov; **rotate it** | open until rotated |
| 14 | Traffic read or changed in transit | TLS and mutual TLS: `brain serve --tls-cert --tls-key [--tls-client-ca]`; the Twin and Guardian connections take `twin.tls` and `guardian.tls` (a CA to trust, a client certificate); `scripts/make_certs.sh` makes a local CA and certificates. **Not on by default**: Compose still runs plain HTTP on a private network, and the handshake cost was not measured | `tests/test_tls.py` (HTTPS served; no client certificate refused; wrong authority refused; the Guardian client and the MCP client connect with a certificate) |
| 15 | A vulnerable dependency or insecure code | `bandit -ll` on `src/`: no medium or high findings (two false positives carry a `nosec` with the reason). `pip-audit` on the locked set (5 Nov): `certifi` and `filelock` upgraded; **`pillow` 12.3.0 has 39 advisories and cannot move to 13.0.0 because `fastembed` pins it below 13**. The Brain never decodes an image (only text is embedded), so the exposure is accepted, not fixed; revisit when `fastembed` moves. A software bill of materials is `docs/sbom.cdx.json` (CycloneDX). `gitleaks` is not installable here; a regex scan of tracked files for keys found none | commands in this row; rerun before the freeze |
| 16 | A Twin on another protocol | HTTP is built (`adapters/twin_http.py`, same envelopes, same signatures; the mock serves it with `python -m mocks.twin --http`). MQTT is built (`adapters/twin_mqtt.py`; readings by broker, the signed body is the only identity, a reorder buffer per sensor, a replay still refused by perception). **WebSocket is open** | `tests/test_twin_http.py`: t13, t14 and t15 decide identically over HTTP and MCP; `tests/test_twin_mqtt.py`: t14 over MQTT decides as t14 |

## What a jury should hear

The Brain does not trust its inputs (signatures, replay checks, ranges, allowlists), does not trust its own agents (read-only tools, deterministic verifiers, one gate), and keeps a record that cannot be quietly changed (hash chain and signed head). The gaps are stated above, not hidden.
