# brain/docs

The City Brain team's documents. The triplet's shared report, pitch and diagrams are in the root [`docs/`](../../docs/).

## Report and Phase 1

| File | What it is |
| --- | --- |
| [../../docs/report.pdf](../../docs/report.pdf) | **The final Phase 1 report** of the triplet (20 pages): Part 0 overview and integration, Part 1 Twin, Part 2 City Brain (pages 9 to 13, ours), Part 3 Guardian, Part 4 Test Book. Where the Brain docs and the report differ, the report is the reference; the README's [Known limitations](../README.md#known-limitations) follow its 2.6 |
| [report/report-city-brain.pdf](report/report-city-brain.pdf) | Our parts of the report (Part 2 The City Brain, with our material for Parts 0 and 4); Part 2 alone, five pages: [report/report-part2-city-brain.pdf](report/report-part2-city-brain.pdf); `report/build.py` rebuilds both |
| [PHASE1-COMPLIANCE.md](PHASE1-COMPLIANCE.md) | Each Phase 1 requirement and the file or command that meets it; the file-by-file map with tests is in the [README](../README.md#phase-1-map-requirement-to-source) |
| [TESTBOOK-brain.md](TESTBOOK-brain.md) | The Test Book scenarios `t12` to `t16` in the Phase 1 fields (generated by `../scripts/gen_testbook.py`) |
| [WALKTHROUGH.md](WALKTHROUGH.md) | Every step of the five scenarios as the timeline screen shows it (generated) |
