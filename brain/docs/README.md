# brain/docs

The City Brain team's documents. The triplet's shared report, pitch and diagrams are in the root [`docs/`](../../docs/).

## Report and Phase 1

| File | What it is |
| --- | --- |
| [report/report-city-brain.pdf](report/report-city-brain.pdf) | Our parts of the report (Part 2 The City Brain, with our material for Parts 0 and 4); `report/build.py` rebuilds it from `report/report-city-brain.html` |
| [PHASE1-COMPLIANCE.md](PHASE1-COMPLIANCE.md) | Each Phase 1 requirement and the file or command that meets it |
| [TESTBOOK-brain.md](TESTBOOK-brain.md) | The Test Book scenarios `d1` to `d4` in the Phase 1 fields (generated by `../scripts/gen_testbook.py`) |
| [WALKTHROUGH.md](WALKTHROUGH.md) | Every step of the four scenarios as the timeline screen shows it (generated) |
