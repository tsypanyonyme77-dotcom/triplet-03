# docs/

- `report.pdf`: built by `uv run --project brain --with pypdf python docs/build_report.py` from `parts/` (the Twin and Guardian teams' PDFs), the Brain's Part 2 and the joint Parts 0 and 4. 20 pages max. Part 0 Triplet Overview & Integration (3, all teams); Part 1 The City / Twin (5); Part 2 The City Brain (5); Part 3 The Guardian (5); Part 4 Test Book (2, all teams).
  Parts 1-3 use the same six subheadings: Role and goals; Architecture; Tech stack and why; Interfaces in/out; Security measures; Known limitations.
- `pitch.pdf`: about 5 slides: problem, solution, architecture, what makes it reliable and trustworthy.
- `diagrams/`: source and exported diagrams.
